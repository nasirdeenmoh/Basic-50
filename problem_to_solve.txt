50 BEGINNER C++ PROBLEMS
=========================
Solve them in order, one at a time. Compile with: g++ file.cpp -o file

--- SECTION 1: VARIABLES & I/O ---
1. Ask for the user's name and age, print "Hello, <name>! Next year you'll be <age+1>."
2. Read two numbers and print their sum, difference, product, and quotient.
3. Convert Celsius to Fahrenheit (F = C * 1.8 + 32).
4. Convert Fahrenheit to Celsius.
5. Read the radius of a circle and print its area and circumference.
6. Read length and width of a rectangle, print area and perimeter.
7. Read a number of seconds, convert and print as hours, minutes, and seconds.
8. Swap two variables' values (try it without a third/temp variable too).
9. Read a price and a discount percentage, print the final price.
10. Read three test scores and print the average.

--- SECTION 2: CONDITIONALS ---
11. Read an integer and say whether it's even or odd.
12. Read three numbers and print the largest.
13. Read three numbers and print the smallest.
14. Read a score (0-100) and print A, B, C, D, or F.
15. Read a year and say if it's a leap year.
16. Read a number and say if it's positive, negative, or zero.
17. Read three side lengths and say if they can form a triangle.
18. Read a character and say if it's a vowel or consonant.
19. Read someone's age and say if they can vote (18+), drive (16+), or neither.
20. Read a number 1-7 and print the corresponding day name (Mon-Sun).

--- SECTION 3: LOOPS ---
21. Read N and print the sum of all numbers from 1 to N.
22. Read a number and print its multiplication table (1-10).
23. Read an integer and print how many digits it has.
24. Print all numbers from 1 to 100 (FizzBuzz: "Fizz" for multiples of 3, "Buzz" for 5, "FizzBuzz" for both).
25. Read a number and calculate its factorial.
26. Read a number and print whether it's prime.
27. Read a number and reverse its digits (e.g. 12345 -> 54321).
28. Read a number and check if it's a palindrome (e.g. 121, 1331).
29. Print the first N terms of the Fibonacci sequence.
30. Read two numbers and find their GCD (greatest common divisor).
31. Read two numbers and find their LCM (least common multiple).
32. Print a right triangle pattern of stars, N rows tall, e.g:
    *
    **
    ***
33. Print a pyramid pattern of stars, N rows tall, centered.
34. Read a number and sum its digits (e.g. 123 -> 1+2+3 = 6).
35. Count how many prime numbers exist between 1 and N.

--- SECTION 4: ARRAYS ---
36. Read 10 numbers into an array, print them in reverse order.
37. Read N numbers into an array, find the largest and smallest.
38. Read N numbers into an array, calculate the average.
39. Read N numbers into an array, count how many are even and how many are odd.
40. Read N numbers into an array, sort them in ascending order (try bubble sort).
41. Read N numbers into an array, search for a specific value and print its index (or "not found").
42. Read N numbers into an array, remove duplicates and print the unique values.
43. Reverse an array in place (without using a second array).

--- SECTION 5: STRINGS ---
44. Read a word and print it in reverse.
45. Read a sentence and count how many words it has.
46. Read a word and check if it's a palindrome (e.g. "racecar").
47. Read a sentence and count how many vowels it contains.
48. Read a word and convert it to all uppercase, then all lowercase.
49. Read a sentence and count how many times a specific letter appears.

--- SECTION 6: A LITTLE HARDER ---
50. Build "Guess the Number": the program picks a random number 1-100 (use rand()),
    the user guesses repeatedly and gets "too high"/"too low" hints until correct.
    Print how many guesses it took.

TIPS
----
- Try each problem for 10-15 min before looking anything up.
- Test edge cases: 0, negative numbers, empty input, very large numbers.
- Once a problem works, try a twist: add input validation, loop until the user quits, etc.
- Come back anytime and share your solution for feedback, or ask for the next set (functions, pointers, structs).
