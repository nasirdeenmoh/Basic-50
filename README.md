# Basic 50
*List of beginner problems for individuals to solve when learning a new language*

Individuals who are interested are to solve these problems to test their profieciency in a particular language and share their results by creating a root directory named after an alias of their choice, then have the languages they solved the problems in as sub-directories inside it, with the files of each solved problem inside their respective directories
```
i.e
Deen (main folder)
    CPP ------ 
              |
    JS  ------|--- Sub-directories
              |
    Py  ------
- Like that. 
```

* *Note the problems to be solved are attached to the problem_to_solve.txt file located in the root of the repo* *
